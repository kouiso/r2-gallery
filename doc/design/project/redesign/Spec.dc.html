R2 Gallery リデザイン 実装仕様

結論: 「どこに何があるか」を見える場所に出す。隠れ操作・重複アイコン・浮いた転送パネルをやめ、4タブ＋ラベル付き操作バーに揃える。色は今の Theme.kt を土台にして、文字・形・余白のルールを足す。

1. 対象と範囲

  • 触るのは KMP版だけ: kmp/composeApp/src/commonMain/kotlin/app/r2gallery/ の App.kt / ui/* / theme/Theme.kt。iOS もビルドが通ること
  • 触らない: src/（Ionic版）と worker/
  • 今ある機能は1つも消さない（下の「引っ越し先」で全部の行き先を決めてある）
  • 画面に出す値は、今のモデルにある値だけ。無い値は出さない（「表示する値」参照）

今回やらないこと

  • ファイルの移動・コピー・名前変更のUI（フォルダ選択の設計が別に要る。アルバム名の変更はやる）
  • アップロード時のアルバム同時追加（転送キューに完了後処理が無い）
  • ゴミ箱の完全削除（APIが無い）・一括一時停止・完了履歴

  • 指を滑らせる範囲選択・ゴミ箱の一括復元

2. ナビゲーション

  • 下タブを4つに: 写真 / アルバム / 取り込み / 設定（今は3つ）
  • 起動画面は今のまま「取り込み」。startDestination は変えない
  • ロック対象: 写真・アルバム・設定（今と同じ GatedGallery）。取り込みはロックしない。ロック画面は入った瞬間に生体認証を自動で出す
  • ライブラリ切替はタイトルのプルダウン（写真・アルバム共通の状態）。ライブラリが1つならプルダウンを出さない
  • 戻る操作: 選択中→選択を解除 / シート→閉じる / ビューア→一覧へ
  • 写真タブ右上は「並び替え」「今すぐロック」の2つだけ。ゴミ箱・取り込み・設定のアイコンは置かない（タブにある）

6. 今ある機能の引っ越し先

  • 並び替え（新しい順など）→ 写真タブ右上
  • フォルダ閲覧（BrowseScreen）→ アルバムタブの「フォルダ」
  • アルバム作成 → アルバムタブ右上＋ / 名前変更・削除 → アルバムの長押しメニューとアルバム詳細の…メニュー
  • アルバム内の前へ・後ろへ・外す → アルバム詳細で1件選択時の操作バー（05b）。読み取り専用なら出さない
  • レビュー情報（ReviewMeta）→ 情報シートの「レビュー」行（ある時だけ）。intentComment と基準ごとの点数・veto まで今と同じ量を出す
  • オフライン保存 → 操作バー「オフライン」/ 全削除 → 設定
  • 引っ張って更新・起動失敗バナー・接続画面・画面ロック無し画面・取り込み履歴 → そのまま（色と寸法だけ新ルール）
  • ロック中は転送バーにも過去の行を出さない（今の fromLedger の隠し方を流用）

7. 表示する値（出典）

表示出典 ファイル名MediaItem.key の末尾 サイズMediaItem.size 追加日時・日付見出しMediaItem.createdAt（端末のタイムゾーン、曜日つき） 保存場所ライブラリ名＋key のフォルダ部分 メモMediaItem.note（無ければ行ごと出さない） 動画マークtype。長さは出さない ゴミ箱の日付TrashItem.deletedAt。サムネは無いので種類アイコン 転送の進みTransferTask の進捗。行のボタン（一時停止/再開/再試行/取り消し）は今の TransferRow の出し分けを流用。完了行は今どおり4秒で消えるビューアの位置「N件目」だけ（ページ読み込みなので総数は出さない）ゴミ箱の保持日数表示用の定数 TRASH_RETENTION_DAYS_DISPLAY = 30 1か所（Worker の既定値に合わせる）

8. 動きの決まり

  • 長押しで選択開始、以後はタップで追加/解除。日付見出しの丸で日ごと選択（指を滑らせる範囲選択は今回やらない）
  • 選択中は下タブと転送バーを操作バーに置き換える
  • 「ゴミ箱へ」の後は「N件をゴミ箱に移しました［元に戻す］」を6秒。元に戻す＝返ってきた trashKey を restore（bulkTrash() を失敗件数だけでなく trashKey も返す形に変える）。アップロード完了の通知より優先し、転送バー・操作バーより上に出す。ビューアから消した時はビューアを閉じてから出す（ビューアは Dialog なので下に隠れる）
  • 復元が 409 なら「同じ名前の項目が元の場所にあるため戻せませんでした」。一部失敗なら「N件中M件を戻せませんでした」
  • 追加ボタンは転送バーがある時はその上、無い時は下タブの16dp上
  • ビューア: タップで上下バーを隠す/出す。動画の時はメモを隠し、再生バーを操作バーの上に出す
  • 取り込みの検出リストは普段たたんだ1行（「3件見つかりました」）。タップで09のシートに開く
  • 読み取り専用ライブラリでは「ゴミ箱へ」「外す」「前へ/後ろへ」を出さず、アップロード先にも出さない（その時だけ確認シートに「読み取り専用は選べません」と添える）
