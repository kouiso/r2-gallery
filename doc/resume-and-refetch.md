# 起動・復帰で画面を保つ条件と、取り直す条件（#24）

#24 の完了条件「画面・一覧・スクロール位置を維持できる条件、再認証や再取得が必要な条件を明文化」の正本。
コードの場所は `flutter/lib/src/state/app_state.dart`（`AppState`・`GalleryState`）と
`flutter/lib/src/albums/album_states.dart`（アルバムの詳細）。

## 保つ物と、その条件

| 場面 | 保つ物 | 条件 |
|---|---|---|
| 完全終了からの起動・OS がプロセスを捨てた後の起動 | ライブラリの一覧と選んでいたライブラリ（`Keys.libraries` の控え）、写真タブの先頭ページ（`ListingCache` の控え） | 控えの接続先が今の接続先と同じで、控えの形が `v: 1` の時。回線を待たずに出し、裏で取り直して置き換える。控えの `cursor` は使わず、続きは回線の先頭ページの後に頼む |
| 裏から前面への復帰（猶予の内） | 一覧の並び・読み進めた位置・`cursor`・開いている画面 | いつも。一覧を先頭から取り直さない |
| 裏から前面への復帰（猶予を超えた） | 同上。ロックの画面が上を覆う | 解除の後も同じ画面に戻る |
| 長く裏にいて署名 URL が切れた | 並び・位置・`cursor` は保ち、読み込み済みの行の URL だけを替える | 行のどれかの URL（原本かサムネ）が切れている時だけ、先頭から読み込み済みの件数ぶん辿って替える（`refreshIfExpired`）。ロック中に戻った時もロックの裏で走る（一覧は `Offstage` で残り、画面はロックが覆う） |
| ビューアを開いたまま URL が切れた | 開いているページ・動画の位置と一時停止 | 同じ項目で URL だけが替わった時（`viewer_screen.dart` の `_appendLoaded`、`video_view.dart` の `didUpdateWidget`）。ロック中に届いた差し替えは解除まで待たせる（ロックの裏で動画を作り直し、OS のメディアセッションをつなぎ直さないため） |

## 取り直す・認証し直す条件

| 条件 | どうなるか |
|---|---|
| 裏にいた時間がロックの猶予を超えた（ロックが効く端末だけ。Web は PIN を設定している時で、タブを隠すと `hidden` が裏扱いになり、猶予を超えて戻ると再ロックする） | ロックが掛かる。解除するまで中身は見えない。署名 URL の差し替えとライブラリの一覧の取り直しはロックの裏で進める |
| 画面が閉じられた（最近使ったアプリから消した）後に戻った | 猶予に関わらず起動と同じロックが掛かる |
| 控えだけで起動し、回線の一覧をまだ取れていない（`librariesFromNet` が false） | ロックの解除の時と、前面への復帰の時（ロック中でも、画面が閉じられた後の復帰でもよい）に一覧を取り直す。前面への復帰の取り直しは、直前の失敗から 30 秒は空ける（圏外で通知シェードなどを出し入れするたびに頼まないため。解除と「再試行」は空けない）。控えの一覧がある間は、取得中なら重ねて頼まない。一覧が全く無い（控えも無い）時は、固まった要求を待たせないよう取得中でも頼み直す |
| URL の差し替えの途中で回線が切れた・相手が一時の不調（5xx）・待てば通る断り（408・429） | 取れた分だけ替え、帯（`error`）は出さない。アルバム一覧の表紙の取り直しも同じで、今のアルバムを残す。表紙の取り直しの最中にアルバムを作成・名前変更・削除したら、その答えは捨てる（手元の変更を古い答えで戻さない） |
| 差し替えの最中に、期限の切れた行を開いた | 差し替えの終わりを待ってから、まだ切れていればその 1 件だけ `objectAt` で取り直して開く。差し替えが走っていなければ、すぐ 1 件を取り直す。取り直せなければ写真タブ・フォルダ・アルバムの詳細のどれも「開けませんでした」の通知（`showOpenFailedNotice`）を出す。引き直しを待つ間の連打は、画面ごとに 2 回目以降を無視する（ビューアを二重に積まない） |
| URL の差し替えが断られた（401・403・404・410） | 直すのに利用者の手が要るので、帯で見せる（`isClientRejection`） |
| 差し替えの途中で取り直し・並び替え・ライブラリ切替が起きた | 差し替えの結果を捨てる（`epoch` が変わる） |
| 接続を外した | ライブラリの控えと一覧の控えを消す。次の接続は回線を待つ |
| 接続先が替わった | 控えの接続先が違うので使わない。回線の答えで控えを書き直す |
| 控えが壊れている・形が違う（`v` が 1 でない） | 使わずに回線の答えを待つ |

## 測る時の目印

`--dart-define=R2_PERF_LOG=true` のビルドで、logcat に `r2g.perf` の行が出る（`flutter/lib/src/diag/perf_log.dart`）。
#24 の作業 D で区間に分けるのに使う。

| ev | 出る所 |
|---|---|
| `main` | 起動の最初 |
| `init.read` | 起動の読み出し（接続・ロックの設定）が終わった |
| `libs.cached` | ライブラリの控えを戻した（`n` は件数） |
| `grid.cached` | 写真タブに一覧の控えを出した（`n` は件数） |
| `libs.net` | 回線からライブラリの一覧を取れた |
| `resume` | 前面へ戻り、ロックの判定が済んだ（`awayMs` は裏にいた時間、`locked` はロックが掛かったか）。画面が閉じられた後の復帰や裏へ回った時刻が無い復帰でも出るが、時間を測っていないので `awayMs` は付かない |
| `resign.done` | 写真タブの署名 URL の差し替えが終わった（`n` は替えた件数、`left` は替えられなかった件数、`pages` は辿ったページ数、`ms` は掛かった時間） |
